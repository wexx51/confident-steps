# Уверенный шаг: сайт + ИИ-помощник (бесплатно, без аккаунтов у посетителей)

`public/` — сайт. `server/server.js` — маленький сервер (Node 18+, без пакетов): отдаёт сайт и передаёт вопросы помощника в Gemini. Ключ хранится только на сервере.

## 1. Бесплатный ключ Gemini
1. Откройте https://aistudio.google.com, войдите обычным Google-аккаунтом.
2. «Get API key» → «Create API key». Скопируйте ключ. Карта не нужна.
Лимиты бесплатного уровня и доступность по странам Google меняет, смотрите на странице ключа. Если выбранная модель недоступна, задайте другую переменной `MODEL` (например `gemini-3.5-flash-lite`).

## 2. Проверить у себя на компьютере
В папке `server`:
- Windows (PowerShell): `$env:GEMINI_API_KEY="ваш_ключ"; node server.js`
- Mac/Linux: `GEMINI_API_KEY=ваш_ключ node server.js`
Откройте http://localhost:3000, в упражнении нажмите «Не получается?» и задайте вопрос. Ответ без пометки «Заготовленная подсказка» пришёл от ИИ.
(Нужен Node 18+: https://nodejs.org)

## 3. Публичная ссылка бесплатно (Render)
1. Положите всю папку проекта в репозиторий на GitHub.
2. https://render.com → New → Web Service → выберите репозиторий. Runtime: Node, Instance type: Free.
3. Start Command: `node server/server.js` (или выберите «Blueprint»: в проекте есть `render.yaml`, он заполнит всё сам). В Environment добавьте `GEMINI_API_KEY` = ваш ключ.
4. Через пару минут Render выдаст ссылку вида `https://имя.onrender.com`. Она открывается у всех без аккаунтов.
На бесплатном тарифе сервер «засыпает» без посетителей, первое открытие может занять около минуты. Откройте ссылку заранее перед показом.

## ИИ-чат со скриншотами
В меню «ИИ-помощник». Можно приложить скриншот: он сжимается в браузере и уходит на ваш сервер, а оттуда в Gemini. На сайте картинки не сохраняются. На странице стоит напоминание закрывать номера, ИИН, карты и коды.

## Защита от перерасхода
12 запросов в минуту с одного адреса и 500 в сутки на весь сайт (`RATE_PER_MIN`, `DAILY_LIMIT`). Это бережёт бесплатный лимит.

## Без сервера
Если сервер не запущен, сайт всё равно работает: помощник отвечает заготовленными подсказками.

## Claude вместо Gemini (платно)
Задайте `ANTHROPIC_API_KEY` вместо `GEMINI_API_KEY`: сервер переключится сам.

## Иконки
Встроены в `public/icondata.js`, источники в `public/ICON_SOURCES.md`.

## Анонимная статистика (бесплатно, Upstash)
Сайт считает только общие суммы: посещения, начатые и пройденные практики, iPhone/Android/Windows/Mac, язык, результаты тренажёра, отметки уверенности. Имена, IP, cookies и тексты не сохраняются. Посетитель может отключить отправку на странице «О проекте»; браузеры с включённым Global Privacy Control ничего не отправляют.
Цифры видны всем на странице сайта `#stats` (ссылка есть в «О проекте»).

Чтобы цифры не обнулялись при перезапуске Render, подключите бесплатный Upstash Redis:
1. https://upstash.com → войдите (карта не нужна) → Create Database → Redis, тариф Free, регион ближе к Render.
2. На странице базы, в разделе «REST API», скопируйте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
3. В Render → ваш сервис → Environment добавьте обе переменные и сохраните. Сервис перезапустится сам.
Без этих переменных статистика хранится в памяти сервера и обнуляется при перезапуске. Токен храните только в Render, в код не вставляйте.

## Работа без интернета и установка на телефон
После первого открытия сайт сохраняет свои файлы в браузере (`public/sw.js`), и практики, шпаргалки и тренажёр открываются без интернета. Сервер при каждом запуске пересчитывает версию файлов, поэтому после деплоя посетители получают новую версию. Как установить сайт на главный экран, написано на странице «О проекте».

## Казахский язык
Третья кнопка «Қазақша» в шапке; ссылка `?lang=kk` сразу открывает сайт на казахском. Переводы лежат в `public/kk.js` (русская строка → казахская), их подхватывает `locale.js` для всех текстов `t(en, ru)` и страницы. Учебные экраны приложений тоже переводятся. Если какой-то строки нет в `kk.js`, показывается русский текст.
Перевод черновой и сделан без носителя языка: перед показом людям его нужно вычитать. Подписи в учебных экранах Kaspi, WhatsApp и Telegram стоит сверить со скриншотами этих приложений на телефоне с казахским языком.
«Прочитать вслух» на казахском появляется, только если в системе установлен казахский голос.
