# App icon sources

Phone and desktop mockups load authentic app artwork from these public sources. An internet connection is required for the icons to appear.

- Android app artwork: current Google Play listings for [Google Photos](https://play.google.com/store/apps/details?id=com.google.android.apps.photos), [Clock](https://play.google.com/store/apps/details?id=com.google.android.deskclock), [Weather](https://play.google.com/store/apps/details?id=com.google.android.apps.weather), [Google Keep](https://play.google.com/store/apps/details?id=com.google.android.keep), [Gmail](https://play.google.com/store/apps/details?id=com.google.android.gm), [Phone](https://play.google.com/store/apps/details?id=com.google.android.dialer), [Messages](https://play.google.com/store/apps/details?id=com.google.android.apps.messaging), [Chrome](https://play.google.com/store/apps/details?id=com.android.chrome), and [Pixel Camera](https://play.google.com/store/apps/details?id=com.google.android.GoogleCamera).
- iPhone and Mac system app artwork: [iOS Icon Pack](https://sysadmindoc.github.io/iOSIconPack/), using standard full-color iOS 18 system icons.
- iPhone Settings artwork: Apple's [official Settings icon](https://developer.apple.com/assets/elements/icons/settings-ios/settings-ios-256x256_2x.png).
- Windows 11 taskbar apps: File Explorer artwork from [Icons8](https://icons8.com/icon/Jw9nt2gzEivq/file-explorer), Chrome from its Google Play app listing, and the Start mark follows the Windows logo.
- macOS Dock: Finder artwork from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Finder_Icon_macOS_Tahoe.png), Safari from Simple Icons, and Messages, Photos, Mail, and Settings from Apple system icon sources.
- Android Settings artwork: the Android Open Source Project [Settings app icon](https://github.com/aosp-mirror/platform_packages_apps_settings/blob/main/res/mipmap-xxxhdpi/ic_launcher_settings.png).

Platform and app names are trademarks of their respective owners. This is an educational mockup and is not affiliated with Google, Apple, or Microsoft.

- WhatsApp, Telegram: icon files supplied by the project author (embedded as x_whatsapp, x_telegram).
- eGov mobile: icon file supplied by the project author (x_egov).
